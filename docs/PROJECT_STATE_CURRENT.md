## 🔁 THE AGENTIC LOOP — CORE VALUE PROPOSITION

The Agentic Loop is what separates Winners from a collection of features. It's the mechanism by which a single user action in one layer creates compounding value across all others — automatically, intelligently, supervised by AI.

```
USER POSTS IN COMMUNITY
         ↓
NOVA detects skill signal from content + engagement pattern
         ↓
OMEGA receives signal → triggers Academy recommendation
         ↓
SAGE tutors the learner (PDF analysis, voice notes, Q&A)
         ↓
User earns verified certificate → SAGE reports to OMEGA
         ↓
OMEGA triggers Work match pipeline
         ↓
CIRCUIT reads job board + freelancer profile → generates match score
         ↓
CIRCUIT writes personalized proposal → user wins first contract
         ↓
ATLAS detects consistent earner → offers vendor onboarding in Market
         ↓
Market enables product and service sales → revenue diversifies
         ↓
OMEGA analyzes full journey → optimizes next recommendation
         ↓
Ecosystem compounds. Loop repeats at higher fidelity.
```

**Every feature, every page, every API must answer:** _Does this strengthen the loop?_

## 🎨 DESIGN SYSTEM — ABSOLUTE LAW

### Universal Design Philosophy

Every Winners platform must communicate: **this is infrastructure built for people who are building something.** Design language: premium fintech meets world-class creative studio — disciplined, confident, unmistakably built for African and diaspora communities who refuse to settle for second-tier tools.

### Code Rules — Zero Exceptions

❌ **NEVER:**

- Use Tailwind classes anywhere in the codebase
- Hardcode hex colors — always use CSS variables
- Create CSS with `document.createElement('style')` — inject via JSX `<style>` tag only
- Omit Phase + Layer comments at the top of files
- Skip the ecosystem context bar on any logged-in page

✅ **ALWAYS:**

- Use CSS variables exclusively: `var(--gold)`, `var(--blue)`, `var(--surface)`, etc.
- Inject CSS via `<style>` tag directly in JSX return
- Follow card pattern: `6px border-radius` + `2px gradient top border`
- Add Phase + Layer comment at file top: `// Phase 2 — Winners Community — CommunityPage.tsx`
- Include ecosystem context bar showing all 9 layer statuses
- Use `req.user!.userId` — never `req.user!.id`
- Scope every DB query by `tenantId`
- Try/catch on every async route handler
- No `any` types. No `@ts-ignore`. Proper interfaces.
- Design mobile-first: 375px baseline, bottom nav on mobile, 44px touch targets minimum
- Motion: 200ms ease transitions, entrance animations with stagger, micro-interactions on hover/focus
- Accessibility: WCAG AA minimum, keyboard navigable, 4.5:1 contrast ratio
